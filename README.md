# DSA - Java Data Structures & Algorithms Practice

This repository is a Java-based collection of algorithm and data-structure practice problems. It contains standalone implementations for common DSA patterns rather than a single application with a formal project structure.

## Project snapshot

- Repository type: educational Java coding practice repo
- Main source directory: `src/`
- Number of Java source files: 79
- Primary focus: arrays, strings, dynamic programming, stacks, hash maps, linked lists, sliding window, prefix sums, sorting, and 2D matrix problems
- Build artifacts: `out/` (generated by the Java compiler/IDE)
- Editor metadata: `.idea/`, `.codex/`

## Topic coverage

The codebase is organized by algorithm category under `src/`:

- `ArrayList/` - list-based exercises
- `Arrays/` - array fundamentals, searching, sorting-adjacent tasks, and pattern problems
- `Arrays2D/` - 2D matrix traversal and transformation problems
- `DP/` - dynamic programming stock and profit solutions
- `HashMap/` - frequency, duplicate, substring, and lookup problems
- `LinkedList/` - custom singly linked list implementation samples
- `Maths/` - number-theory and prime-related practice
- `PrefixSum/` - prefix-sum techniques for subarray problems
- `SlidingWindow/` - window-based optimization problems
- `Sorting/` - merge sort implementation
- `Stack/` - stack operations, calculator parsing, bracket checks, and adapter patterns
- `String/` - string transformation and compression tasks
- `TwoPointersAndSlidingWindow/` - two-pointer and sliding-window techniques

## Files and code patterns

Most files follow a consistent pattern used in coding-practice repos:

- Each Java file usually contains a focused problem solution
- Classes are often named after the problem or algorithm
- Input is commonly read using `Scanner`
- Output is printed through `System.out.println(...)`
- Many examples are self-contained and can be compiled/run independently

The root-level `src/Main.java` is a simple Java command-line demo showing how to compile and execute Java classes. The root-level `src/Palindrome.java` is a separate standalone palindrome implementation.

## How to run the project

This project does not include Maven or Gradle configuration. It is intended to be compiled directly with the Java compiler.

### Compile a single file

```bash
javac -d out src/Arrays/TwoSum.java
java -cp out Arrays.TwoSum
```

### Compile the root demo

```bash
javac -d out src/Main.java
java -cp out Main hello world
```

### Compile all source files

On Unix-like systems:

```bash
find src -name "*.java" -print0 | xargs -0 javac -d out
```

On Windows PowerShell:

```powershell
Get-ChildItem .\src -Recurse -Filter *.java | ForEach-Object { javac -d out $_.FullName }
```

## Notes

- The repository is focused on learning and problem solving, not on packaging or deployment.
- Generated output in `out/` is not meant to be edited by hand.
- The `.gitignore` file excludes IDE and build output noise such as `out/` and `.idea/`.
- Some class names intentionally duplicate names across packages (for example, `Prime` exists in both `Arrays` and `Maths` packages), which is valid Java because packages separate them.

## Contribution and usage

This repository is best used as a reference for typical DSA interview and coding-practice implementations. You can open specific problem files under `src/<Topic>/` and run them independently for testing and study.
